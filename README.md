# COSC 455 Project 2: Functional Programming

| Part | File |
|---|---|
| I. Warmup | `rust/src/bin/warmup.rs`, `sml/warmup.sml` |
| II. Binary Addition/Subtraction | `rust/src/bin/binary.rs`, `sml/binary.sml` |
| III. Rust Math Translation | `rust/src/bin/translation.rs` |
| IV. Scheme Preparation | `scheme/prep.rkt` |
| V. Scheme Math Translation | `scheme/translation.rkt` |
| VII. Drunk Homer (Extra Credit) | `rust/src/bin/homer.rs` |

## Running

- **Rust:** from `rust/`, run `cargo run --bin warmup` (or `binary`, `translation`, `homer`)
- **SML:** paste the file into [SOSML](https://sosml.org/)
- **Scheme:** open the file in DrRacket and click Run
